## The excuse

> "My Wi-Fi is fine, my camera works, my mic works — I just can't find one good reason to join."

No technical difficulties, no dying laptop, no mysterious "connection issues" — every piece of gear works perfectly. The only thing missing is a single convincing reason to show up. Brutally honest, and exactly why it lands.

## How this entry works

`main.ts` writes the excuse to `/output/entry.txt` — that's the whole entry. One line, no excuses about the excuses. Nothing fancy, just the line itself, ready to be judged.

## Run it

```bash
npx tsx main.ts
cat /output/entry.txt
```
